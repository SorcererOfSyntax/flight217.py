# FLIGHT 217 : HIJACKED

## What is this game?

A text-based moral thriller set on a hijacked flight.

**You are Jake.** You're flying home with your pregnant wife, Sabrina. Everything is peaceful until 20 terrorists take control of the plane with 160 passengers and 6 crew members.

**Every choice costs.**

Your conversations with Sabrina affect her emotions. Your actions during the hijack affect:
- Your morality (did you do the right thing?)
- Your honor (how you'll be remembered)
- Whether Sabrina survives
- How the terrorists react

**Three possible endings:**
1. ❄️ **Cold Case** - The plane crashes. No answers. No survivors.
2. 🩸 **Save Wife, Kill Many** - She lives. But at what cost?
3. 💔 **Tragic Loss** - A devastating ending shaped by grief and consequence.
No ending is completely happy. No decision is completely right.

## How to run it

### Requirements

### Steps
1. Save the game code as `flight217.py`
2. Open terminal / command prompt
3. Navigate to the folder containing the file
4. Run the command from code file.
